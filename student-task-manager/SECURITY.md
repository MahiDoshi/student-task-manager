# Security Policy

## Reporting a Security Issue

Please do not publicly disclose security vulnerabilities.

For security-related issues, contact the project maintainer privately.

## Supported Version

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |
| < 1.0   | No        |

## Security Practices

This project uses:

- CodeQL
- Dependabot
- Secret Scanning where available
- Push Protection where available
- GitHub Actions
