# Student Task Manager

A simple browser-based task manager created as a demonstration project for GitHub-based software development.

## Features
- Add tasks
- Set Low/Medium/High priority
- Mark tasks completed
- Delete tasks
- Filter tasks
- Local browser storage
- Automated Node.js tests
- GitHub Actions CI
- GitHub Pages deployment configuration

## Run locally
Open `index.html` in a browser.

For tests, use Node.js 20+:

```bash
npm test
npm run lint
```
